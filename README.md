# AI Context Engineering — A Practical Guide

> A comprehensive, hands-on guide to setting up AI-powered development workflows using Omniroute, Kilo Code, and Claude Code.

## 🎯 What is This?

This is a **living documentation site** built by a self-taught developer documenting their journey from copy-pasting code into ChatGPT to building a proper AI-powered development workflow.

Learn how to:
- 🔧 Set up **Omniroute** to access 1.6 billion free AI tokens daily
- 🤖 Integrate AI assistants directly into your IDE
- 📝 Write effective context files that teach AI how to help you
- ⚡ Go from hours of manual coding to instant design iterations
- 🎓 Use AI as a tutor, not just a code generator

## 🚀 Key Topics Covered

### 1. **Setting Up Omniroute**
Complete step-by-step guide to installing and configuring Omniroute with multiple AI providers:
- OpenRouter (free tier)
- OpenCode (zero auth)
- Kiro AI & Antigravity (free Claude models)
- NVIDIA NIM (high-tier models)

### 2. **Writing Context Files**
Learn how to create `CLAUDE.md` files that customize AI behavior:
- Tutor mode for learning
- Project-specific conventions
- Large codebase management

### 3. **Real-World Examples**
Actual use cases from real projects:
- Rapid design iteration (hours → seconds)
- Typo detection across large codebases
- Theme testing without manual coding

### 4. **Best Practices**
Hard-earned lessons from actual usage:
- When to use Ask Mode vs Auto-Generate
- How to avoid common setup mistakes
- Who benefits most from this workflow

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/ferhatdaoud/AI-Context-Engineering-A-Practical-Guide.git

# Navigate to project directory
cd AI-Context-Engineering-A-Practical-Guide

# Install dependencies
npm install

# Start development server
npm run dev
```

The site will be available at `http://localhost:5173`

## 🌐 Deployment

### Deploy to Vercel (Recommended)

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```

### Deploy to Netlify

```bash
# Build the project
npm run build

# Deploy the dist folder to Netlify
```
